هذه النقاط تحتاج فحصاً بصرياً وعملياً مباشرة على الجهاز

الشاشة والقطع الأصلية
الإعدادات ← عام ← معلومات ← قطع وخدمة
ابحثي عن "قطعة Apple الأصلية" بجانب الشاشة والبطارية والكاميرا. "قطعة مجهولة" = قطعة متغيرة بمركز غير معتمد.
Face ID / Touch ID
قفّلي الجهاز وجرّبي فتحه بالوجه أو البصمة
Face ID معطل غالباً = الشاشة اتغيرت بدون معدات Apple المعتمدة.
مهم مؤشر الماء
افتحي درج الشريحة — المؤشر الأبيض داخله
المؤشر أبيض = طبيعي · أحمر أو وردي = تعرض للماء.
جودة الشاشة
Dead pixels، Burn-in، True Tone، سطوع
ضعي السطوع 100% وشوفي على خلفيات ألوان مختلفة. True Tone: الإعدادات ← شاشة العرض والسطوع.
الكاميرا والفلاش
صوّري في إضاءة عادية ومنخفضة، اختبري الفلاش
افتحي مركز التحكم وفعّلي المصباح — يضيء فوراً بدون وميض.
الهيكل والأزرار
انحناء، فجوات الشاشة، أزرار، منفذ الشحن
ضعي الجهاز على سطح مستوٍ — لا انحناء. اختبري كل الأزرار وكابل الشحن.
