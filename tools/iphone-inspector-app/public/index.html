🧪 الاختبارات الوظيفية

اختبري كل وظيفة بنفسك وسجّلي النتيجة

قطع Apple الأصلية
الإعدادات ← عام ← معلومات ← قطع وخدمة
  1. افتحي الإعدادات ← عام ← معلومات ← قطع وخدمة
  2. ابحثي عن كل قطعة — "قطعة Apple الأصلية" = طبيعي
  3. "قطعة مجهولة" أو "غير قادر على التحقق" = قطعة مستبدلة
Face ID / Touch ID
قفّلي الجهاز وجرّبي فتحه
  1. قفّلي الشاشة واتركي الآيفون
  2. اقتربي بوجهك — المفروض يفتح فوراً (Face ID)
  3. لو "تعذر تفعيل Face ID" = الشاشة اتغيرت بمركز غير معتمد
جودة الشاشة
Dead pixels، Burn-in، True Tone، سطوع
  1. ارفعي السطوع 100% — شوفي على خلفية بيضاء كاملة
  2. شوفي نقاط ميتة أو احتراق (Burn-in) على خلفية داكنة
  3. الإعدادات ← شاشة العرض — لو True Tone غير موجود = شاشة مستبدلة
الشاشة اللمسية
دقة اللمس وحساسية كل الزوايا
  1. افتحي Notes وارسمي خطوطاً في كل زوايا الشاشة
  2. تأكدي إن اللمس مستجيب في كل الأركان والحواف
  3. جرّبي Multi-touch: افتحي الصور وكبّري بإصبعين
الصوت والمكبر
مكبر القاع + سماعة الأذن + Ring/Silent
  1. شغّلي أي موسيقى وارفعي الصوت — يُسمع نظيف بدون طشطشة
  2. اتصلي بنفسك — السماعة الأذنية فوق الشاشة تشتغل
  3. اضغطي زر Ring/Silent على الجانب — يهتز ويتحوّل للصامت
المايكروفون
3 مايكروفونات — أمام، أسفل، خلف
  1. افتحي Voice Memos (المذكرات الصوتية) وسجّلي صوتك
  2. اشغلي التسجيل — يُسمع الصوت واضحاً بدون تشويش
  3. جرّبي مكالمة فيديو — الطرف الآخر يسمعك كويس
الكاميرا والفلاش
كل العدسات + الفلاش + الكاميرا الأمامية
  1. افتحي الكاميرا وجرّبي كل تكبير (0.5× 1× 2× 5×)
  2. افتحي مركز التحكم وفعّلي المصباح — يضيء فوراً
  3. انتقلي للكاميرا الأمامية — صورة نظيفة بدون ضبابية
  4. شوفي العدسات تحت الضوء — لا خدوش أو بقع
الاهتزاز والتابتيك
Taptic Engine + محرك الاهتزاز
  1. الإعدادات ← الأصوات والتعليقات الصوتية ← اضغطي "تشغيل الاهتزاز للاختبار"
  2. يُفترض أن تشعري بنبضات نظيفة ومنتظمة
  3. لو اهتزاز خشن أو طنين = محرك الاهتزاز متلف
الشحن ومنفذ الكابل
Lightning / USB-C + شحن لاسلكي
  1. وصّلي شاحن أصلي — يظهر رمز الشحن فوراً
  2. جرّبي كابلين مختلفين — لو شاحن يشتغل والثاني لا = المشكلة في الكابل
  3. الإعدادات ← البطارية — تأكدي إن "يشحن" ظاهر
مهم مؤشر الماء
درج الشريحة — المؤشر الأبيض داخله
  1. افتحي درج الشريحة بالدبوس
  2. المؤشر أبيض = طبيعي ✓
  3. أحمر أو وردي = تعرّض للماء ✗ — الجهاز قد يموت بعد أيام
الهيكل والأزرار
انحناء، فجوات، أزرار الصوت والجانبي
  1. ضعي الجهاز على سطح مستوٍ — لا انحناء في الهيكل
  2. مرّري إصبعك على الحواف — لا فجوات بين الشاشة والهيكل
  3. اضغطي كل الأزرار: صوت↑ صوت↓ Mute الجانبي — كل واحد يستجيب
