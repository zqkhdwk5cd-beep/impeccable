# نظام المبيعات والمخزون — تطبيق macOS Native

تطبيق Desktop حقيقي مكتوب بـ Python + PySide6 (Qt6).
يعمل بدون متصفح أو Terminal بعد البناء.

---

## المتطلبات

- Python 3.12+
- macOS 12+ (يعمل أيضاً على Linux/Windows)

---

## التشغيل السريع (بدون بناء)

```bash
# 1. تثبيت الاعتماديات
pip install -r requirements.txt

# 2. تشغيل التطبيق
python main.py
```

---

## بناء تطبيق macOS قابل للتثبيت (.app)

```bash
chmod +x build.sh
./build.sh
```

ستجد الملف الناتج في:
```
dist/نظام المبيعات.app
```

اسحبه إلى `/Applications` أو أرسله لأي شخص. يعمل بدبل كليك.

---

## قاعدة البيانات

البيانات محفوظة تلقائياً في:
```
~/Library/Application Support/SalesPOS/sales_pos.db
```

**لا تضيع البيانات عند تحديث البرنامج** — الملف منفصل عن الكود.

---

## الوظائف

| القسم | الوظائف |
|---|---|
| **لوحة التحكم** | مبيعات اليوم والشهر، الربح، المخزون المنخفض، رسوم بيانية |
| **نقطة البيع** | شبكة منتجات + سلة + خصم + إتمام البيع |
| **المنتجات** | إضافة/تعديل/حذف + صور + فئات + تكلفة/سعر/هامش |
| **المخزون** | عرض المخزون + إعادة تعبئة |
| **التقارير** | فلتر زمني + رسوم إيرادات وأرباح + أعلى المنتجات |
| **سجل المبيعات** | كل الفواتير + عرض الفاتورة بنقرة مزدوجة |
| **إعدادات المالك** | محمية بكلمة مرور — اسم المتجر، حد الخصم، تغيير كلمة المرور، backup/restore |

---

## اختصارات لوحة المفاتيح

| الاختصار | الوظيفة |
|---|---|
| `Alt+1` | لوحة التحكم |
| `Alt+2` | نقطة البيع |
| `Alt+3` | المنتجات |
| `Alt+4` | المخزون |
| `Alt+5` | التقارير |
| `Alt+6` | سجل المبيعات |
| `N` | إضافة منتج (في صفحة المنتجات) |

---

## النسخ الاحتياطي

من **إعدادات المالك**:
- **تصدير**: يحفظ ملف `.json` في أي مكان تختاره
- **استيراد**: يستعيد البيانات من ملف `.json` سابق
